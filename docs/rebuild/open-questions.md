## Not questions, but you should know

- **Regulatory facts.** Primary sources (consumerfinance.gov, fanniemae.com, ecfr.gov, law.cornell.edu) are not reachable
  from the build container. Facts in `design.md` §a are marked S (confirmed by search on 19 Nov 2026), R (from the
  July research) or K (cited, not re-fetched). The K items need one pass from a machine with access before the tour
  copy is final; allowing those four hosts in the session's network settings would let an agent do it.
- **What is real.** The pod server, access control, signatures, status lists and the proof are real and run in the
  visitor's browser. Sign-in is simulated, and each organisation's back office is a script in the same browser. The
  site says so on every app.
- **The old tour did not enforce permissions** (every request ran as Alex). The rebuild does; this is the largest
  change in what the demo can honestly claim.
- **`@jeswr` packages are still not on npm** (only `fetch-rdf` is). The rebuild vendors packed tarballs from a
  `solid-sdk` checkout, as `idea-sandbox` does. `@sparq-org/solid-server` 0.1.8 is on npm, so that tarball and its
  patch go.
