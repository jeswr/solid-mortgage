## Rules that apply to every pager

- **Concept-demo status** stated once per pager; role-first framing ("modelled on X", never
  "by X"); no logos or trade dress; nothing that reads as an offer or solicitation of credit
  (decision 0002 + R1–R8 addendum).
- **No GSE product marks** — GSE programmes are described, never named by product identifier
  (R3).
- **Every claim traceable**: bracketed numbers = `docs/research/mortgage-process.md` source
  list; org-map = `docs/research/org-map.md`; role-map sheet = the internal EDMA member/role
  directory (4 Jun 2026).
- **Caveats that travel** (research-gaps §3): Mastercard membership publicly unconfirmed; the
  eOriginal ~92% eNote share is dated January 2022; Microsoft, if mentioned, is a CDMC
  *workgroup participant*, never "member".
- **Screenshots pending**: each pager carries a `SCREENSHOT-TODO` marker to be replaced once
  the apps are deployed (PLAN item 3).
