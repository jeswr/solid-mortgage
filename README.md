# solid-mortgage

**Solid mortgage demo**: a US home purchase, from pre-qualification to loan servicing, told
through thirteen apps of twelve fictional organisations that all work from one person's
[Solid](https://solidproject.org/) pod. Built for the EDMA Solid Community of Practice.

> CONCEPT DEMO. Every organisation and person in it is fictional. Sign-in is simulated; access
> control, signatures and proofs are real. Everything runs in your browser and nothing is sent to
> a server.

The rebuild is under way (decision [0017](decisions/0017-static-rebuild.md)). One static site:
each organisation app is served under `/<slug>/`, and the pods run in the visitor's browser in
a service worker backed by sparq's wasm Solid server (`@sparq-org/solid-server`). The previous
Next.js apps were deleted; they remain in git history.

## Run it

```bash
pnpm install
pnpm run build      # builds every app and assembles dist/
pnpm run preview    # serves dist/ on a free loopback port with production routing
pnpm run gate       # lint, checks, build, typecheck, tests
pnpm run test:e2e   # Playwright suites against the built site
```

Node 24 and pnpm 10.4.1 (`packageManager`). Agents: read [`AGENTS.md`](AGENTS.md) first.

## Layout

- `apps/<slug>/` — one Vite + React app per organisation, plus `welcome`; `apps/_template/` is
  the starting point; `apps/vocab/` is the mort vocabulary site (its own Vercel project)
- `packages/` — `demo-kit` (registry types, links, calendar, trust banner, contract types),
  `pod-runtime`, `tour`, `lens` (the engine), `data-model`, `vc-kit`
- `content/` — the organisation registry (`orgs.ts`) and each demo's seed, tour and copy
- `tools/` — site build and routing, local server, vendoring, lint and insignia checks
- `e2e/` — acceptance suite; `video/` — narrated recordings
- `docs/research/`, `decisions/` — grounding research and the decision log

## Deployment

One Vercel project, `solid-mortgage`, builds `dist/` on every merge to `main`
(`vercel.json`, generated by `tools/site-routes.mjs`). Pull request previews build only when
the pull request is labelled `preview`. The vocabulary namespace
`https://solid-mortgage-vocab.vercel.app/mort#` stays a separate, permanent project.

Every commit is reviewed by roborev (`.roborev.toml`).
